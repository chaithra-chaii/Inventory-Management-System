# Inventory Management System

## Project Overview
The Inventory Management System is a Python-based application developed using SQLite3. It helps users manage product details and maintain inventory records efficiently.

## Features
- User Sign Up and Sign In
- Add new products
- View product details
- Update product information and stock quantities
- Delete product records
- Store data using an SQLite database

## Technologies Used
- Python
- SQLite3

## Database
The project uses SQLite3 to store inventory information. The database is managed through the `database.py` file, and the database file is named `inventory.db`.

## How to Run the Project
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

```bash
python inventory.py
```

5. Follow the on-screen instructions to sign up, sign in, and manage inventory.

Make sure `inventory.py`, `database.py`, and any required database files are in the project folder.
